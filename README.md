# BetwithBetter

BetwithBetter is a responsive sports betting web application that allows users to view matches, place bets, and track updates in an intuitive and mobile-friendly interface.

---

## 🌟 Features
- **Multi-page design**: Home, Matches, My Bets, Account, and Updates pages.
- **Responsive layout**: Seamlessly adapts to desktop, tablet, and mobile screens.
- **Interactive elements**: Hover and focus effects for better user experience.
- **Clean typography**: Consistent font families and readable text across all pages.
- **Visual appeal**: Well-chosen color palette and decorative elements.

---

## 🛠️ Technologies
- **HTML5** for structure
- **CSS3** (single external stylesheet)
  - Flexbox/Grid for layout
  - `@media` queries for responsiveness
  - Pseudo-classes (`:hover`, `:focus`) for interactivity
- Optional future enhancements: JavaScript for live odds and real-time updates.

---
